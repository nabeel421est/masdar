# مصدر — النظام المحاسبي

نظام محاسبي عربي/إنجليزي: الحسابات وكشوف الحساب، سندات القبض والصرف، العملاء والموردون، المخزون، المبيعات والمشتريات، وتقارير PDF تُرسل عبر واتساب.

التطبيق ملف واحد: `index.html`.

## التشغيل
- داخل Claude: تُحفظ البيانات في قاعدة بيانات Claude الخاصة بالتطبيق.
- على GitHub Pages: تُحفظ البيانات في مشروع Supabase «Masdar» وتظهر على كل الأجهزة. عند أول فتح على أي جهاز يُطلب بريد وكلمة مرور حساب الشركة في Supabase، ولا يصل إلى البيانات إلا البريد المسجل في جدول `masdar_members`.
- إعداد قاعدة البيانات في `supabase/schema.sql`.

أول دخول: اسم المستخدم `admin` وكلمة المرور `admin`، ثم غيّرهما من الإعدادات.
